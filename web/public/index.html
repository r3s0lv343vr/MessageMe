How it works

MessageMe is a self-messaging reminder app. You write a note to yourself, pick when it should arrive, and it shows up as a letter from you — on the lock screen and in Received.

  • Chat-style notes from you, not task-manager cards
  • Overnight letters arrive at your envelope hour
  • Lock-screen notification is the personal note
  • Quiet calendar: unopened mail, not habit streaks
  • Offline-first on Android; optional Firebase later

How to view the real app

  1. Install Android Studio on your computer.
  2. Clone or download the repo r3s0lv343vr/MessageMe, branch main.
  3. In Android Studio: File → Open the repo folder.
  4. Wait for Gradle sync (elephant / Sync Now) to finish.
  5. Device Manager → create a Pixel phone with API 36 (or API 33) → Start it.
  6. Click the green Run button (app configuration).

Firebase (google-services.json) is optional just to open and try the app. Without it, everything works offline; cloud sync stays off.
