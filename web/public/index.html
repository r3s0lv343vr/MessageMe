MessageMe

Message yourself. Remember what matters.

An Android reminder app that feels like a chat with you — schedule tasks, get envelope-style notifications, and track them on a colour-coded calendar. Works offline.

View / run on Android Open pull request

What you’re looking at

This page is a project display for the MessageMe Android app. The real product runs on an Android phone or emulator — not inside this browser.

  • Chat-style self reminders with title, date, and optional time
  • Default 3:00 AM local time when no time is chosen
  • Calendar todo view with orange / green / red / blue day colours
  • Envelope notifications — not alarm-clock alerts
  • Offline-first Room storage; optional Firebase sync later

How to view the real app

  1. Install Android Studio on your computer.
  2. Clone or download the repo r3s0lv343vr/MessageMe, branch feature/message-me-android-app.
  3. In Android Studio: File → Open the repo folder.
  4. Wait for Gradle sync to finish.
  5. Device Manager → create a Pixel phone with API 36 (or API 33) → Start it.
  6. Click the green Run button (app configuration).

Firebase (google-services.json) is optional just to open and try the app. Without it, everything works offline; cloud sync stays off.
